## 原理
基于安卓的webveiw组件开发，核心思想是把APP模拟为浏览器。在模拟浏览器的基础上包装出APP，以此优化移动端的使用体验。

# 本软件一切数据处理均在APP完成，数据来源为学校的教务系统
## 核心数据处理
- 所有教务数据通过本地Web组件与学校服务器直接交互
- 用户身份凭据采用设备级RSA非对称加密存储（密钥永不离开设备）
- 课程表等敏感数据仅缓存在沙盒隔离存储区

## 辅助功能数据
- 通过友盟SDK收集【去标识化】的：
  ▫️ 基础信息（软件版本/用户规模）
- 严格不包含：
  ▫️ 学号、姓名等身份标识
  ▫️ 课程内容、考试安排等教务数据  
  ▫️ 设备唯一标识符（如IMEI/IMSI）

## 数据安全承诺
- 用户可通过设置关闭密码本地存储功能

## 风险提示
※ 越狱/root设备可能破坏沙盒隔离机制
※ 设备物理丢失可能导致加密数据被暴力破解
